# CamaraD — публичная страница и готовые сборки

Здесь только сайт, скомпилированная браузерная игра, APK и видеоинструкция.
Исходный проект, серверные секреты и ключи подписи сюда не входят.

## Включение сайта один раз

Settings → Pages → Build and deployment → Source → GitHub Actions.
После push в main workflow «Publish CamaraD website» публикует папку site.
Адрес: https://nicolenkoe.github.io/CamaraD-downloads/

Версия и список изменений: site/release.json.
Ссылки сайта: site/site-config.json; пути относительные, сайт можно перенести на другой домен.
Видео: реальные экраны CamaraD; женская нейросетевая русская озвучка Piper Irina, естественный темп 0.94. Новая дорожка синтезирована целыми фразами, громкость выровнена до -16 LUFS.
Сетевой сервер игры пока не запущен.

## Пошаговая инструкция — третья редакция

18 глав, реальные клики и перемещения стиков, красная подсветка и указатель. Голосовые реплики относятся к конкретным действиям; для рыболовных терминов задан словарь фонетических ударений. Записанное ожидание поплавочной поклёвки сокращено с явным пояснением в ролике. В игре при этом ничего не изменено.

## Обновления Android и каталог версий

Начиная с 0.23 приложение проверяет открытые файлы GitHub Raw при запуске:
- `site/updates/stable.json` — только стабильные сборки;
- `site/updates/testing.json` — последняя доступная сборка, включая тестовые.

В настройках приложения → «Версия» можно отключить тестовые обновления или проверить наличие новой версии вручную. При наличии обновления предлагаются «Обновить» и «Позже»; окончательная установка подтверждается стандартным окном Android.

Сборки 0.22 и старее нужно один раз обновить вручную поверх старого приложения: их старый адрес проверки не указывает на этот репозиторий.

Каталог сайта: `site/releases.json`. Сейчас опубликованы только тестовые 0.21, 0.22, 0.23. Стабильный канал подготовлен, но стабильных сборок пока нет. Нельзя просто переименовывать тестовые сборки в стабильные без проверки.

Новая публикация подготавливается в закрытом исходном проекте скриптом `scripts/prepare-github-release.py`: versionCode увеличивается, APK подписывается прежним ключом, размер/SHA-256/сертификат проверяются. Файлы опубликованных версий не перезаписываются. Ключи подписи сюда не загружаются.
