# CamaraD — публичная страница и готовые сборки

Здесь только сайт, скомпилированная браузерная игра, APK и видеоинструкция.
Исходный проект, серверные секреты и ключи подписи сюда не входят.

## Включение сайта один раз

Settings → Pages → Build and deployment → Source → GitHub Actions.
После push в main workflow «Publish CamaraD website» публикует папку site.
Адрес: https://nicolenkoe.github.io/CamaraD-downloads/

Версия и список изменений: site/release.json.
Ссылки сайта: site/site-config.json; пути относительные, сайт можно перенести на другой домен.
Видео: реальные экраны CamaraD; женская нейросетевая русская озвучка Piper Irina, естественный темп 0.97. Новая дорожка синтезирована целыми фразами, громкость выровнена до -16 LUFS.
Сетевой сервер игры пока не запущен.
